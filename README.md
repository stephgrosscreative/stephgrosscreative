# Stephanie 98 — Portfolio v2.0

A static HTML/CSS/JavaScript portfolio designed to feel like a Windows 98 desktop.

## Open locally
Double-click `index.html` or drag it into Chrome, Safari, or Firefox.

## Publish with GitHub Pages
1. Create a new public GitHub repository.
2. Upload every file and folder from this directory to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

## Included in v2.0
- Draggable, minimizable, maximizable application windows
- Windows 98 taskbar, Start menu, and live clock
- Clippy welcome assistant
- Embedded Nikon, Sony, FUJIFILM, and Devil-Dog video players
- Devil-Dog campaign case study
- Picture Viewer-style photography galleries
- Commercial eyewear portfolio viewer
- About in Notepad and résumé in WordPad
- My Computer, Internet Explorer, Contact, Paint, Solitaire, and Merlin Recycle Bin Easter egg
- Responsive mobile layout
